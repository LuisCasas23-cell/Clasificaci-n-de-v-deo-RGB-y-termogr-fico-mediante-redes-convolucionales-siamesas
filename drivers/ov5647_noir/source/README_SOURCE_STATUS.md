```text

```

```text

```

## Estado actual del repositorio

Los contenidos exactos de esos archivos no están disponibles en los archivos recuperados del proyecto en este momento.

Por integridad técnica, este repositorio **no incluye una reconstrucción aproximada** de esos fuentes.

Cuando se recupere una copia original de la Jetson o del directorio:

```text
~/ov5647_work/
```

los archivos podrán añadirse aquí después de verificar que correspondan a la versión utilizada con:

```text
JetPack 4.6.1
L4T R32.7.1
Kernel 4.9.253-tegra
```

La documentación de instalación y configuración presente en las carpetas superiores sí corresponde al entorno utilizado en el proyecto.
